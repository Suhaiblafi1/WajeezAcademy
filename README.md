# أكاديمي وجيز — Wajeez Academy

منصة تعلم عربية تبدأ بالفهم قبل التعليم: تشخيص حتمي (8–14 سؤالا متكيفا) يرشّح مسارا واحدا مفسَّرا أو خطة مركبة موسومة، ثم رحلة دورات بمخرجات يراجعها مدربون بشريون.

## التشغيل السريع

```bash
npm install
npm run api:dev     # الخادم + قاعدة PostgreSQL المدمجة على 7101/5433
npm run dev         # الواجهة على 3000 (بروكسي /api تلقائي)
```

## الفحص الكامل

```bash
npm test                    # محرك التشخيص + محاكاة 12 شخصية
npm run test:e2e            # كل اختبارات الخادم (134) — بالتسلسل
npm run audit:diagnostic    # + audit:methodology / audit:catalog* / audit:diagnostic-*
npm run lint && npm run build
```

## الحواجز الآلية

عشرة حواجز تفشل بدل أن تمرّ صامتة. تسعة منها تعمل في `.github/workflows/ci.yml`
على كل دفع وكل طلب دمج، والعاشر داخل الخدمة نفسها وقت النشر. وكلها قابلة للتشغيل محليا:

> `test:e2e` كان يعمل في CI ولا يُذكر في هذه القائمة، فسقط من العادة اليدوية:
> بقيت أربعة اختبارات دفعٍ حمراء بعد دمج دورات الكتالوج — منها الحارس الذي
> يمنع أن يدفع متعلّم عن أربع دورات فيُسجَّل في واحدة — بينما «الحواجز خضراء»
> تُقال في كل مرّة. وحاجزٌ لا يُذكر في قائمةٍ تُقرأ هو حاجزٌ يُنسى.

```bash
npm run catalog:validate        # أ-١ · بوابة المصدر قبل أي استيراد
npm run ci:journeys-baseline    # ب-٣ · خط أساس رحلات التشخيص التسع
npm run ci:lint-baseline        # ب-٣ · دين التلويم لا يزيد
npm run ci:overlays             # ج-٢ · الملفات المولّدة لا تنحرف عن مولّدها
npm run ci:coverage-baseline    # أ-٤ · تغطية القياس لا تتراجع
npm run ci:question-waste       # هـ-١ · هدر مقاعد الأسئلة لا ينمو (~30s)
npm run test:e2e                # ب-٣ · الخادم على قاعدة حقيقية: الدفع والتسجيل (~6د)
npm run a11y:audit              # ب · الإتاحة مقيسة (يحتاج الواجهة والخادم)
npm run pathway:audit           # أ-٣ · تدقيق المسارات قبل التفعيل
npm run audit:catalog -- --source          # د-٢ · تدقيق الملفات بلا قاعدة بيانات
npm run audit:recommendation-universe      # د-١ · خصائص الفضاء لا أعداده
npm run audit:question-waste               # هـ-١ · أي سؤال لا يغيّر جوابُه شيئا (مضاد للواقع)
npm run audit:catalog                      # ج-١ · شبكة أمان على القاعدة الحيّة (تحتاج قاعدة)
```

> حاجز النشر (ج-١) يعمل داخل الخدمة لا في CI: لا يمكن نشر مسار بلا مجال،
> و`npm run audit:catalog` يكشف صفوفا سبقت الحاجز في قاعدة قائمة.

| الحاجز | ما يمنعه | كيف يُحدَّث عند تغيير مقصود |
|---|---|---|
| بوابة المصدر | مهارة بخطأ إملائي · مسار بلا جمهور أو مجال · دورة مشار إليها ولا وجود لها · معرّف مكرَّر · ساعات خارج المدى. تُستدعى داخل `importCatalog` نفسه فلا مسار استيراد يتخطّاها. وتُبلّغ (بلا إفشال) عن ضعف القياس: مسارات بلا مهارة مقيسة · أسئلة تقيس مفاتيح ليست مهارات · تباعد `measured_by` عن المحرك | أصلح المصدر — لا تُعطَّل البوابة |
| خط أساس الرحلات | تغيّر سلوك المحرك بلا انتباه: مسار مختلف أو ثقة مختلفة أو تسلسل أسئلة مختلف لإحدى الشخصيات التسع | `npm run simulate:v2_1-journeys` والتزم `docs/diagnostic-v2_1/journeys.v2_1.json` في الطلب نفسه |
| دين التلويم | خطأ أو تحذير تلويم **جديد**. لا يفشل على الدين القائم (٦ أخطاء و٧ تحذيرات react-hooks) فCI أحمرُ دائما يعلّم تجاهل الأحمر | `npx tsx scripts/lint-baseline.ts --update` بعد إصلاح فعلي |
| تدقيق المسارات | تفعيل مسار ناقص: بلا دورات أو بلا ملف تعريفي أو بلا مجال أو بمهارات غير مقيسة | أكمل بيانات المسار |
| التراكبات المولّدة | تحرير يدوي لملف يقول «مولَّد — لا يُحرر يدويًا» (`question-meta` · `skill-layers` · `question-plan` · `skills.slim` · بطاقات القرار)، أو تغيير في المولّد بلا إعادة توليد والتزام. وهذه الملفات تحدد أي سؤال يراه المحرك وأي مهارة تُقاس — فانحرافها انحراف في التوصية | `npm run build:v2-overlays` و`npm run build:v2_1-overlays` ثم التزم الناتج في التغيير نفسه |
| تغطية القياس | تراجعٌ في ما يستطيع المحرك قياسه: مسار يفقد آخر مهارة مقيسة له · مهارة مقيسة تخرج من سطح B2C · سؤال جديد يقيس مفتاحا غير مسجَّل (يُسأل المتعلم ويُهمَل جوابه). **يقيس الاتجاه لا القيمة**: الحال القائم (١٠ مسارات خاملة · ٨ مهارات مقيسة) لا يُفشله، والتراجع عنه يُفشله | حسّن ثم `npx tsx scripts/coverage-baseline.ts --update`؛ ولو كان التراجع مقصودا فوثّقه وحدّث خط الأساس في التغيير نفسه |
| الإتاحة | عنصر تفاعلي بلا اسم مقروء · محطة Tab بلا حلقة تركيز مرئية · عنصر يُركَّز عليه وهو مخفي · `tabindex` موجب · منطقة `main` غائبة أو متكررة · قفزٌ في ترتيب العناوين · تمرير أفقي عند تكبير ٢٠٠٪ أو ٤٠٠٪. يُقاس على ٨ صفحات محليا و٤ عامة في CI، وخط الأساس اليوم **صفر واقعة** | أصلح الواقعة — الرسالة تقول ما تمنعه على المستخدم لا رقم قاعدة؛ ولو كان التراجع مقصودا: `npm run a11y:audit -- --update` |
| حاجز النشر | نشر مسار معتمد ناقص: بلا مجال (ج-١) · بلا جمهور أو هدف · بلا دورات · بلا تحوّل قبل/بعد (ج-٣). كلها تُنتج «جوكرا»: كيانا ينافس الجميع أو لا يُوصى به أبدا. يعمل داخل `validateDrafts` بـ**نفس تعريف** جاهزية المعالج (`pathwayReadiness`) لا نسخة ثانية منه، فيسدّ مسار النشر الذري كله ولا يمسّ منشورا قائما | أكمل ما ينقص من الشاشة نفسها — معالج المسار يعرض الخطوات الخمس وأسبابها |
| تدقيق الفضاء | كيان نشط بلا جمهور محدد («جوكر» ينافس الجميع) أو بلا مجال أو بمهارة غير مسجَّلة. **بالخصائص لا بالأعداد**: تدقيقٌ يفشل عند كل إضافة مشروعة يُعتاد تجاهله فيموت | أكمل بيانات الكيان، أو وثّق ثغرة معروفة في `KNOWN_AUDIENCE_GAPS` بما يحلّها |

## قواعد ثابتة

- محرك التشخيص حتمي deterministic — لا LLM في اختيار الأسئلة أو التوصية.
- لا أسماء مدربين ولا قصص نجاح تُعرض كحقيقية قبل توثيقها واعتمادها.
- الدورة كيان مركزي واحد ترتبط به المسارات والقوالب مرجعيا — لا نسخ مكررة.
- لا أسرار في Git؛ `storage/private/` و`.env` و`.pgdata/` مستثناة دائما.
- **الإصدارات:** عند كل محطة كبرى يُنشأ وسم موقّع `v<N>-<name>` برسالة عربية كاملة (ملاحظات إصدار مجمّعة بالمحاور + قسم تحقق) ويُدفع لـ GitHub مباشرة — آخرها `v9-learner-experience`، والتالي `v10-*`.
