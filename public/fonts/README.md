# خطّ محتوى الدورات

يُقرأ متنُ الوحدة قراءةً طويلة، لا يُمسح مسحَ واجهة. ولذلك أُفرد له خطّ:
`Avenir Arabic` بقرار صاحب المنتج — مقصورا على `LessonBody` وحده، لا على
الواجهة كلّها.

## ما يوضع هنا

ملفّاتٌ بصيغة **woff2** من حزمة الاستضافة الذاتيّة (Self-Hosting Web Font Kit)
في حساب Monotype:

```
public/fonts/avenir-arabic-400.woff2   (Book)
public/fonts/avenir-arabic-500.woff2   (Medium)   — اختياريّ
public/fonts/avenir-arabic-700.woff2   (Heavy)    — اختياريّ
```

الأسماء أعلاه هي ما يقرؤه `src/index.css`؛ سمِّ ملفّاتك بها ولا شيء آخر
يتغيّر. والصفحة تعمل قبل وضعها وبعده — الارتداد إلى `IBM Plex Sans Arabic`.

## لماذا woff2 لا otf

- **الترخيص**: ترخيص سطح المكتب لا يُبيح التضمين على الويب؛ ذلك ترخيص
  Web Font منفصل، وحزمتُه تأتي woff2/woff. ولا يُوضع في هذا المجلّد ملفٌّ
  من موقع تنزيلٍ عامّ: المستودع عامٌّ والموقع تجاريّ، والأثر يبقى في تاريخ
  Git ولو حُذف الملفّ.
- **الحجم**: woff2 مضغوطٌ لهذا الغرض — يقارب ثلث حجم otf، ومتنُ الدورة
  يُقرأ على الهاتف قبل الحاسوب.

## بلا ملفّ

لا شيء يُكسر: `@font-face` تشير إلى ملفٍّ غير موجود فيتخطّاه المتصفّح
بصمت، ويُقرأ المتن بالخطّ الاحتياطيّ نفسه الذي تُقرأ به المنصّة.
