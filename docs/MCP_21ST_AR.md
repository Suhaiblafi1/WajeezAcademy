# خادمُ 21st.dev عبر MCP — من أين يأتي المكوّن، وأين يسكن مفتاحُه

مصدرُ مكوّناتِ واجهةٍ جاهزةٍ بصيغة shadcn/ui، يصل إلى وكيلِ الشيفرة (Claude
Code وأمثالِه) خادمَ MCP بدل النسخِ واللصقِ من متصفّح. ويوافق مكدّسَ هذا
المستودَع كما هو: React 19 · Tailwind 3 · shadcn/ui بأسلوب `new-york` ·
أيقونات `lucide` — وهي عينُها ما في `components.json`.

## الملفّ ولماذا هو في Git

`.mcp.json` في جذر المستودَع. يقرؤه Claude Code لكلّ من استنسخ المشروع، فلا
يُعاد إعدادُ الخادم على كلّ جهاز. **ولا مفتاحَ فيه**: القيمةُ
`${API_KEY_21ST}` تُوسَّع من بيئةِ الصدفةِ وقتَ التشغيل، فيبقى ما في Git
وصفَ الوِصلةِ لا سرَّها — وهي القاعدةُ الثابتة: لا أسرارَ في Git مطلقا.

وهو غيرُ `.claude/settings.local.json` المُهمَل في `.gitignore`: ذاك إذنُ
جهازٍ واحد، وهذا وِصلةٌ يتقاسمها الجميع.

## المفتاح — مرّةً واحدةً على كلّ جهاز

١) مفتاحٌ من <https://21st.dev/settings/api-keys> بصيغة `21st_sk_…`.

٢) يُصدَّر في ملفّ الصدفة (`~/.zshrc` أو `~/.bashrc`)، لا في المستودَع:

```bash
export API_KEY_21ST=21st_sk_…
```

**ولا يوضع في `.env`**: ذاك يقرؤه خادمُ المنصّة لا Claude Code، ووضعُه فيه
يُنتج خادما يبدو موصولا وهو يردّ ٤٠١.

٣) التحقّق: `/mcp` داخل الجلسة (أو `claude mcp list` من الطرفيّة) يُظهر
`21st` متّصلا. وأوّلُ استعمالٍ يستأذن في خادمِ المستودَع — موافقةٌ واحدةٌ ثمّ
يُحفظ القرار.

## من أين جاءت هذه القيم

من الحزمةِ نفسِها لا من تخمين: `@21st-dev/cli@1.17.0` هو ما يكتبه
`21st init --client claude --write`، والقيمُ أعلاه مطابقةٌ لما يُخرجه
(`https://21st.dev/api/mcp` · ترويسة `x-api-key`). والحزمةُ القديمة
`@21st-dev/magic` صارت وسيطا رقيقا إلى المسار ذاته، فلا داعيَ لها في إعدادٍ
جديد.

> **وجلساتُ Claude Code السحابيّة لا تصل 21st.dev** — بروكسي الخروج يحجب
> النطاق. فهذا الخادمُ يعمل في الجلسات المحلّيّة، ويصمت في السحابيّة صمتَ
> الشبكة لا صمتَ الإعداد.

## الحصّة

البحثُ وقوائمُ البيانات مجّانيّة؛ **جلبُ كودِ المكوّن** (`get_component`) هو
الفعلُ المحسوب، وللحسابِ المجّانيّ سقفٌ يوميّ صغير.

## وما يدخل منه يمرّ بما يمرّ به سواه

مكوّنٌ مستوردٌ شيفرةٌ كأيّ شيفرة: يمرّ بـ`npm run verify` وخضرةِ CI قبل
الدمج، ولا استثناء له. **والاتّجاهُ والعربيّةُ ليسا خيارا**: مكتبةُ المصدر
تكتب لليسار-إلى-اليمين افتراضا، فكلُّ مكوّنٍ يُراجَع على RTL وعلى الخطّ
والمصطلح قبل أن يستقرّ في `src/components/`.
