# رسالة تسليم — لأي وكيل يستلم مشروع أكاديمية وجيز

> انسخ هذا النص كأول رسالة في جلسة أي وكيل جديد (Claude أو غيره)، أو وجّهه لقراءة هذا الملف مباشرة.

---

أنت تستلم مشروع «أكاديمية وجيز» (Wajeez Academy) — منصة تعلم عربية (React + Vite + Tailwind RTL، خادم Fastify، PostgreSQL عبر Prisma).

المستودع: github.com/Suhaiblafi1/WajeezAcademy (فرع main — شجرة العمل نظيفة وكل شيء مدفوع).

## خطوتك الأولى إلزامية وبالترتيب

1. اقرأ `README.md`
2. اقرأ `docs/RUNBOOK_AR.md` كاملا — هو دليل التشغيل والتدقيق الشامل وفيه الأقسام 15–17: نتيجة تدقيق «خادم بلا شاشة» المُغلق، والبنود المؤجلة، وحالة الاستلام الحالية. لا تبدأ أي عمل قبل قراءتهما.

## التشغيل محليا

```bash
npm install
npm run api:dev   # الخادم + قاعدة PostgreSQL مدمجة على 7101/5433 — لا Docker
npm run dev       # الواجهة على 3000، بروكسي /api تلقائي
```

الفحص: `npm test` + `npm run test:e2e` + `npm run lint && npm run build`

ملاحظة: vitest قد يعلق عند الخروج — اقتله بـ `pkill -9 -f "vitest run"` إن لزم.

## قواعد ثابتة لا تُخالف

- محرك التشخيص حتمي deterministic — ممنوع إدخال LLM في اختيار الأسئلة أو التوصية.
- لا أسماء مدربين ولا قصص نجاح تُعرض كحقيقية قبل توثيقها واعتمادها.
- الدورة كيان مركزي واحد — لا نسخ مكررة.
- لا أسرار في Git إطلاقا (`.env` و `storage/private/` و `.pgdata/` مستثناة دائما).
- كل عمل ينتهي بـ commit + push لـ `origin main`، وعند كل محطة كبرى وسم موقّع `v<N>-<name>` برسالة عربية كاملة — آخر وسم `v12-production-hardening` (ترويسات أمان شاملة + إصلاح اختبار النشر)، والتالي `v13-*`.
- بوابة CI جاهزة محليا في `.github/workflows/ci.yml` (tsc + 332 اختبارا) — لم تُرفع: صلاحية `workflow` غير ممنوحة للرمز الحالي. تُرفع يدويا من واجهة GitHub أو بعد تحديث الرمز.

## حالة المشروع الآن

- المنصات الأربع (زائر/طالب/مدرب/إدارة) مكتملة الشاشات — تدقيق 178 نقطة API مغلق، والاستثناء الوحيد `GET /api/trainer/me` موثق بأولوية منخفضة.
- لا حسابات مبذورة عمدا — أنشئ حسابات اختبار محليا عند الحاجة (القسم 8 من RUNBOOK).
- المزودون المؤقتون قرارات مرحلية لا أخطاء: Zoom يدوي، دفع اختباري، قنوات بريد/واتساب غير مربوطة (الأقسام 12–14).
