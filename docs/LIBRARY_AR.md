# المكتبة — كيف تُضاف مادّة

المكتبة تبويبٌ في بوابة المتعلّم يعرض موادّ **خارج الدورات**: فيديو، مقال،
قالب، منشور، ملفّ PDF، نصّ، أو كتاب. كلّ مادّة **تُفتح في تبويب جديد على
مصدرها الأصلي** ولا تُضمَّن داخل الصفحة.

## لماذا لا تُضمَّن

تضمين مشغّل يوتيوب أو إطار إنستغرام داخل صفحات المنصّة يُنزل متتبّعات الطرف
الثالث على كل زائر ويبطّئ الصفحة، ولا يضيف على الرابط شيئا يستحق ذلك. الرابط
الخارجي أنظف وأسرع وأصدق: المتعلّم يرى اسم المضيف قبل أن ينقر.

## متى يظهر التبويب

**لا يظهر إلا حين تكون فيه مادّة منشورة واحدة على الأقل.** تبويبٌ يَعِد بمكتبة
ثم يفتح على فراغ أسوأ من غيابه.

## أين تُضاف المادّة

في `src/data/catalog/core-catalog.v2.json`، تحت مفتاح `library_resources`
(يُنشأ إن لم يكن موجودا) في أعلى الملف:

```json
"library_resources": [
  {
    "id": "LIB-001",
    "kind": "video",
    "title_ar": "عنوان المادّة",
    "description_ar": "سطر واحد يقول ما فيها (اختياري)",
    "url": "https://…",
    "source_ar": "اسم الجهة أو القناة (اختياري)",
    "minutes": 12,
    "skill_slugs": ["public_speaking"],
    "sort_order": 1
  }
]
```

| الحقل | إلزامي | ملاحظة |
| --- | --- | --- |
| `id` | نعم | فريد؛ حذفه من الملفّ يحذف المادّة من القاعدة |
| `kind` | نعم | `video` · `article` · `template` · `post` · `pdf` · `text` · `book` |
| `title_ar` | نعم | العنوان كما يراه المتعلّم |
| `url` | نعم | **https فقط** — الروابط غير الآمنة تُحجب في المتصفّح |
| `description_ar` | لا | سطر واحد؛ يُحذف الحقل حين لا وصف |
| `source_ar` | لا | الجهة أو القناة |
| `minutes` | لا | مدّة تقريبية |
| `skill_slugs` | لا | مهارات مسجَّلة في `skills.v1.ar.json` — غير المسجَّل يُرفض |
| `sort_order` | لا | الأصغر أوّلا؛ الافتراضي صفر |

## ثمّ

```bash
npm run catalog:validate     # يرفض قبل أي كتابة: نوع مجهول، رابط غير https،
                             # معرّف مكرّر، مهارة غير مسجَّلة
npm run catalog:import
npm run catalog:publish
```

المكتبة تَرِث حوكمة المحتوى القائمة (مصدر → تحقّق → استيراد → نشر) بلا شاشة
إدارة جديدة، والتقليم تلقائيّ: ما بقي في الملفّ يبقى، وما حُذف منه يُحذف من
القاعدة.
