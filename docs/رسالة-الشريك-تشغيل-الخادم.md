# رسالة إلى الشريك صاحب حساب Hetzner

> ## ✅ نُفِّذ — ولا يُرسَل هذا النصُّ بعد اليوم
>
> **النشرُ الآليُّ يعمل منذ ٧ سبتمبر ٢٠٢٦.** مهمّةُ `cron` كلَّ خمس دقائق
> تشغّل [`scripts/deploy-watch.sh`](../scripts/deploy-watch.sh)، فأيُّ دمجٍ
> إلى `main` يصل الموقعَ وحدَه. والدليل: `curl -s https://www.wajeezacademy.com/api/version`
> يُعيد بصمةَ آخر التزامٍ مدموج.
>
> ويُحفَظ النصُّ لأنّه يشرح **لماذا** كان يلزم — لا ليُرسَل. ومن أراد
> تركيبَه على خادمٍ جديد فأمرٌ واحدٌ يكفي:
> `bash scripts/install-auto-deploy.sh` ([`deploy/README.md`](../deploy/README.md)).
>
> **⚠️ وكان فيه عنوانُ خادمٍ مكتوبٌ بالأرقام** — وقد انتقلت المنصّةُ بعده إلى
> جهازٍ آخر، فصار العنوانُ يدلّ على خادمٍ ليس هو الإنتاج. فحُذف: العنوانُ
> يُقاس بـ`dig +short www.wajeezacademy.com` ولا يُكتب في نصّ.


> نصٌّ جاهزٌ للإرسال كما هو. المطلوبُ منه **أمرٌ واحدٌ يُنفَّذ مرّةً واحدة**،
> ولا يُطلب منه بعده شيء.
>
> ولمن يريد التفصيل التقنيّ: [`رسالة-المبرمج-النشر-الآلي.md`](رسالة-المبرمج-النشر-الآلي.md).

## المشكلة باختصار

كلُّ تحديثٍ يُكتب للموقع يبقى في GitHub ولا يصل الخادمَ حتّى ينسخه أحدٌ إليه
يدويّا. ولا أحدَ يفعل ذلك بانتظام، فالموقعُ الظاهرُ للناس متأخّرٌ عن العمل
المنجَز. وأنا لا أملك دخولا إلى الخادم، فلا أستطيع إصلاحَها بنفسي.

## الحلّ: أمرٌ واحد

من الطرفيّة على الخادم (SSH، أو Console من لوحة Hetzner):

```bash
cd /opt/wajeez && bash scripts/install-auto-deploy.sh
```

*(إن لم يكن المسار `/opt/wajeez` فهو حيث نُسخ المستودَع على الخادم.)*

هذا كلُّ المطلوب. والأمرُ **يفحص قبل أن يفعل**: يقف عند أوّل شرطٍ ناقصٍ
برسالةٍ تقول ما ينقص بالضبط، ولا يغيّر شيئا حينها. وتشغيلُه مرّتين لا يضرّ.

## ماذا يفعل

| | |
|---|---|
| ينشر نسخةَ الموقع الحاليّة | بترتيبٍ يبني الجديدَ **قبل** لمس ما يعمل — فإن أخفق شيءٌ بقي الموقعُ القديمُ يخدم |
| يجدول فحصا كلَّ ٥ دقائق | يسأل GitHub: هل من جديد؟ فإن كان، ينشره وحدَه |
| يشغّل خدمةً خلفيّة | تذكيراتُ الجلسات ورسائلُ المنصّة والنشرُ المجدول |

## وما لا يفعله — وهذا ما يهمّك

- **لا يخرج من الخادم مفتاحٌ ولا كلمةُ مرورٍ ولا سرّ.** الاتّجاهُ من الخادم
  إلى GitHub لا العكس: الخادمُ يسأل، ولا يُسأل.
- **لا يفتح منفذا ولا يمنح أحدا وصولا** — لا لي ولا لغيري.
- **لا يغيّر شيئا في إعدادات الخادم** غيرَ سطرٍ واحدٍ في جدول المهامّ.

## والتراجع

```bash
crontab -e     # ثمّ احذف السطر الذي فيه deploy-watch.sh
```

سطرٌ واحدٌ يُحذف، ويعود كلُّ شيءٍ كما كان. لا شيءَ غيرُه يتغيّر.
