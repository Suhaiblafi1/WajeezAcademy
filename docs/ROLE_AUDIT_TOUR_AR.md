## ١ · التشغيل قبل أيّ شيء

الخادمُ يشغّل قاعدةَ Postgres المدمجةَ بنفسه على المنفذ `5433` — فلا تُشغّل قاعدةً
يدويّا، ولا تمرّر `DATABASE_URL`. وترتيبُ الأوامر مقصود.

```bash
# ١) الخادم — يُقلع القاعدة المدمجة معه. المنفذ 7101 لا 3000
env -u DATABASE_URL PORT=7101 npx tsx server/index.ts

# ٢) الترحيلات وحسابات الديمو (مرّة واحدة، وإعادتها لا تضرّ)
npm run -s db:deploy && npm run -s db:generate && npm run -s seed:demo

# ٣) الواجهة
npx vite --port 3000
```

الدخول من **`/auth`** — وليس `/login`.

- كلمةُ المرور الموحَّدة لحسابات الديمو: `Wajeez-Demo-2026`
- لإيقاف الواجهة: `kill $(lsof -t -i:3000)` — و`pkill -f "vite"` يقتل صدفتَك أنت.
- اختباراتُ الخادم تُشغَّل بملفّ إعدادها وحدَه:
  `npx vitest run -c vitest.server.config.ts server/tests`.
  تشغيلُها بلا `-c` يجعل الملفّات تتصادم على القاعدة فتسقط بلا سبب.
- فحصُ الأنواع بمشروعين لا بواحد: `tsconfig.app.json` و`tsconfig.node.json`.

## ٣ · الشاشات بحسب البوّابة

أربعُ بوّاباتٍ و٥١ شاشة. حارسُ كلٍّ في `src/components/RequireRole.tsx`، ووصلُها
في `src/App.tsx`.

### الإدارة — ٢٠ شاشة · محروسة

يجوزها ستّةُ أدوار، والشريطُ الجانبيّ يُرشَّح بالصلاحيات: من لا حبّةَ له يرى «لا
صلاحيات مفعّلة». ثلاثةُ أقسام: الأكاديمية · الأمور الفنّية · الصلاحيات العامّة.

### الطالب — ١٩ شاشة · ⚠️ بلا حارس أدوار

**افحص ما يراه مدرّبٌ أو زائرٌ يفتحها مباشرةً بالعنوان.**


### المدرّب — ٧ شاشات · محروسة

أربعُ حبّاتٍ فقط لدور `trainer` — وأكثرُ حراسته بالانتماء للشعبة
(`assertCohortTrainer`) لا بالصلاحيات. **تحقّق أنّ مدرّبا لا يرى شعبةً ليست له.**


`AdvisorProfile` — وهو جدولٌ سقط ترحيلُه مرّة، فتأكّد أنّه موجود.


## ٤ · ما جُرِّب وما لم يُجرَّب

هذا هو سببُ وجودِ هذه الورقة: **الجولةُ لم تكتمل.**

| الدور | الحال | ما جُرِّب فعلا في المتصفّح |
|---|---|---|
| مدير النظام | ✅ جُرِّب | اللوحةُ كاملة: إنشاءُ حساب، تكليفُ مهمّة، الإيقافُ والحذفُ النهائيّ، العمولة، سجلُّ الأثر، فلاترُ الشعب، فرزُ الكتالوج، الإجراءاتُ الجماعيّة |
| المدير الأكاديمي | ⚠️ جزئيّا | استقبالُ تكليفٍ وإنجازُه، وغيابُ نموذج التكليف عنه. لم تُفحص شاشاتُه الاثنتان والخمسون |
| المتعلّم | ⚠️ جزئيّا | الدخولُ فقط. لم تُفحص أيٌّ من التسع عشرة شاشة |
| المدرّب | ❌ لم يُجرَّب | — |
| المستشار | ❌ لم يُجرَّب | — |
| الزائر | ⚠️ جزئيّا | بوّابةُ الإتاحة تفحص خمسَ صفحاتٍ عامّة آليّا. لم تُجرَّب رحلةُ شراءٍ كاملة |
| العمليات · التشخيص · المالية · الدعم | ❌ لم يُجرَّب | لا حسابَ ديمو لها أصلا |

## ٥ · ابدأ من هنا — أعطابٌ من صنفٍ يتكرّر

كلُّ واحدٍ من هذه وقع فعلا في هذا المستودع وأُصلح. ابحث عن أشباهها: **الصنفُ
يتكرّر حتّى لو أُغلق موضعُه.**

### ١) نطاقٌ يُكتب بالدمج لا بالتقاطع

خدمةُ الطلبة كانت تكتب `{...where, userId}` فيطمس `userId` شرطَ المستشار، فيقرأ
أيَّ طالبٍ بمعرّفه. القاعدة: قيدُ النطاق يُضاف بـ`AND` لا بالنشر. افحص كلَّ
`where` فيه نشرُ كائن.

### ٢) واجهةٌ تجزم بما لا تعلم

«أُنشئ الحساب ووصلته دعوة» كان نصّا ثابتا، والخادمُ وحدَه يعرف أأُرسل البريدُ أم
لا. ابحث عن كلّ رسالةِ نجاحٍ مكتوبةٍ في الواجهة تصف أثرا يقع في الخادم.

### ٣) رقمٌ يُعرض بحسابٍ خاطئ

عمولةُ المستشار كانت تسقط حين تُغلق الحالة، وتُحسب على مشترياتٍ سبقت معرفتَه
بالعميل. وتقييمُه كان مقيَّدا بما تعتمده الإدارة — والمخطَّط يمنع ذلك. **كلُّ رقمٍ
يُعرض لصاحب حقٍّ يحتاج قراءةَ استعلامه لا قراءةَ عنوانه.**

### ٤) قائمتان لشيءٍ واحد

قائمةُ أحداثِ التحليلات كانت مكرّرةً بين الواجهة والخادم فرُدَّت أحداثٌ حيّة
بـ422. وأيّامُ الأسبوع كانت رموزا في القاعدة ونصّا حرّا في النموذج. اسأل عن كلّ
ثابتٍ: أله مصدرٌ واحد؟

### ٥) ما لا يمسكه اختبار

نموذجٌ في المخطَّط بلا ترحيلٍ ينشئ جدولَه، وحزمةُ خادمٍ باليةٍ تترك مساراتٍ ميّتةً
على الإنتاج. لكلٍّ الآن بوّابة — شغّلهما قبل أيّ دفعة:

```bash
npm run ci:migrations   # لكلّ نموذجٍ ترحيلٌ ينشئ جدولَه
npm run ci:bundle       # api/index.js مطابقٌ لشيفرة الخادم
```

## ٦ · ثلاثةُ فخاخٍ تُضيّع ساعة

1. **بوّابة الإتاحة تحتاج الواجهةَ حيّةً على 3000.** إن كانت مطفأةً أبلغت عن خمسِ
   وقائعَ وهميّة — ليست انحدارا، شغّل `vite` وأعِد.
2. **الحزمةُ مصغَّرة.** البحثُ فيها عن اسمِ دالّةٍ بلا معنى (تُختصر)؛ المساراتُ
   والنصوصُ العربيّة وحدَها تنجو، والعربيّةُ مخزَّنةٌ بصيغة `\uXXXX` فتُفكّ قبل
   البحث.
3. **لام الجرّ تبتلع الألف.** «للسلسلة» لا تحتوي «السلسلة» — فاختبارُ
   `not.toContain` على عربيّةٍ متشابهة يمرّ لسببٍ غير الذي كُتب له. استعمل وسما
   صريحا لا عبارةً طبيعيّة.

## ٧ · مسلكٌ مقترح للجولة

بالترتيب — كلُّ خطوةٍ تُهيّئ ما بعدها.

1. **الزائر:** الرئيسية ← التشخيص كاملا ← المسار ← لوحُ الشراء ← «بريدٌ مقابل كود
   الخصم». قارن الرقمَ المعروضَ بالرقم في الفاتورة.
2. **المتعلّم:** شراءٌ بمفاتيح `sk_test_` ← العودة إلى `/student/learning` ←
   المتنُ والواجباتُ والجلسةُ القادمة ← الشهادة ← تذكرةُ دعم. وجرّب **الإلغاء**
   أيضا لا النجاحَ وحدَه.
3. **المدرّب:** شعبةٌ مسندةٌ ← تصحيحٌ ← اقتراحُ تأجيل ← «مستحقّاتي». وتأكّد أنّه لا
   يبلغ شعبةً ليست له بتغيير المعرّف في العنوان.
4. **المستشار:** حالةٌ مسندةٌ ← ملاحظةٌ ومتابعة ← طلبُ خصم ← «عمولتي» و«تقييمي».
   وتأكّد أنّه لا يقرأ حالةً ليست له.
5. **الأدوار الأربعة بلا ديمو:** أنشئ لكلٍّ حسابا وادخل به، وتأكّد أنّ الشريطَ
   الجانبيّ لا يعرض إلّا ما يملكه فعلا.
6. **حدُّ الرتبة:** امنح دورا أدنى حبّةَ `admin.users.manage` بالتفويض، وجرّب أن
   يوقف مديرَ النظام. يجب أن يُردّ بـ`rank_exceeded`.
