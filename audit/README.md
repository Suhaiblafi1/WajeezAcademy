# `audit/` — أدواتُ فحصٍ تُشغَّل يدويّا، لا جزءٌ من البناء

هذه اثنان وعشرون سكربتَ فحصٍ كُتبت في جولاتٍ سابقة. **لا يستدعيها البناءُ
ولا CI ولا أيُّ سكربتٍ في `package.json`** — فمن قرأ الملفّاتَ فظنّها أدواتَ
تشغيل، فهي ليست كذلك.

## ما يُقرأ منها اليوم

| الملفّ | لماذا يبقى |
|---|---|
| `full-audit.mjs` | أساسُ جولةِ الأدوار: يدخل بالحسابات، ويصوّر، ويلتقط أخطاءَ الكونسول ونداءاتَ `/api` الفاشلة والانسيابَ الأفقيّ والنصوصَ المسرَّبة. بُنيت عليه جولةُ تقرير ٢٠٢٦-٠٩. |
| `UX-AUDIT-2026-08-20.md` · `GLOBAL-LEARNING-UX-2026-08-20.md` | تقريران — نتائجُ لا أدوات. تُقرآن مع تقرير ٢٠٢٦-٠٩ لا بدلَه. |

## وما لا يُلتزَم

**اللقطاتُ لا تدخل Git.** كانت ١٢٥ لقطةً بـ١٣ ميغابايت، ولا سطرَ يقرؤها:
تُثقل كلَّ استنساخٍ وتُوهم أنّها مرجع. واللقطةُ دليلٌ على لحظتها — تُنتَج
بأمرٍ واحدٍ متى احتيج إليها. و`.gitignore` يستثني `audit/*.png`.

وأدلّةُ التقارير المقصودةُ لها موضعٌ آخر: `docs/audit-2026-09/tour/` —
مُختارةٌ ومضغوطةٌ ومُشارٌ إليها من نصّ التقرير، فلكلّ صورةٍ فيها سببُ بقاء.

## البوّاباتُ الحقيقيّة — وهي في `scripts/` لا هنا

```
npm run ci:a11y          # سبعُ قواعدِ إتاحةٍ في المظهرَين، وحجمُ الهدف على هاتف
npm run ci:lint-baseline # لا دَينَ تلويمٍ جديد
npm run ci:migrations    # لكلّ نموذجٍ ترحيلٌ ينشئ جدولَه
npm run ci:bundle        # حزمةُ الخادم مطابقةٌ للشيفرة
npx tsx scripts/status-checks.ts --check   # قيدُ كلّ حالةٍ يطابق تعليقَه
```
