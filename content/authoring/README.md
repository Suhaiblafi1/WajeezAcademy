# مصادرُ المتون المؤلَّفة

هذه هي **النسخةُ المصدريّة** لما يُدخَل إلى الكتالوج، وليست نسخةً منه:

```
<moduleId>.body.md      المتن — دروسٌ يفصلها «## »
<moduleId>.checks.txt   التمارين — صيغة س: / - / + / ش: / م:
<moduleId>.scenario.txt سيناريو القرار — موقف · عقدة · نص · > خيار · أثر · إلى · تأمل
```

والإدخالُ بأمرٍ واحد، ولا يُلصق نصٌّ في JSON بيد:

```
npx tsx scripts/apply-authoring.ts content/authoring          معاينة
npx tsx scripts/apply-authoring.ts content/authoring --apply  كتابة
npx tsx scripts/audit-authoring.ts --check                    بوّابةُ السياسة
```

**ولماذا تُحفظ المصادرُ هنا وقد صارت في الكتالوج؟** لأنّ المراجعةَ البشريّةَ
شرطُ النشر (`draft → in_review → published`)، والمراجعُ يقرأ متنا في ملفٍّ
مقروءٍ لا سلسلةً فيها `\n` داخل ملفٍّ من أربعمئة وحدة. فالفرقُ في طلب الدمج
هو ما يُراجَع، والكتالوجُ أثرُه.

**وما ليس له ملفٌّ هنا لا يُمسّ**: الأداةُ تكتب في الوحدات التي تجد لها ملفّا
وحدَها، فلا يُتلف غيابُ ملفٍّ متنا مؤلَّفا قبله.
